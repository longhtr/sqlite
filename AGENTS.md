6. **Integration and claims.** Port coherent subsystems and connect real production paths. Aggregate parsing treats `count(*)` as zero arguments only when the star immediately precedes the closing parenthesis. Invocation shims for collation-aware built-ins must provide a valid context `iOp` and preceding operation `p4.pColl`; `minMaxStep()` interprets non-null user data as maximum, not minimum. Anonymous deserialized databases use a private persistent MemoryVfs backend, not named-memdb last-close semantics. A named shared memdb registry entry must retain an anchor file handle for the store lifetime; otherwise closing the initializer's final transient VFS handle destroys the image before the first pager opens it. Scalar functions invoked by database-less prepared programs must not assume `sqlite3_context.pOut.db` is non-null; use the profile limit fallback when only a limit is needed. Report compilation, differential evidence, integration, and assurance separately. Registration is not integration until prepared SQL resolves and executes it. Public filename APIs return the user-visible database filename, never an internal storage alias such as the memdb key. After a failed incremental-blob seek, the handle is permanently invalidated: subsequent read, write, and reopen calls return abort until close, matching `blobSeekToRow()` and `sqlite3_blob_reopen()`. Expanded SQL renders unbound parameters as `NULL`; do not preserve placeholder text in stale fixtures. If preparation returns generic logic error, inspect initialization/lookup first. Native probes prepare/step statements separately before interpreting multi-statement `sqlite3_exec()` failure. When DDL integration on a small-page fixture returns `too_big`, check whether the leaf-only schema writer exhausted page capacity before blaming SQL parsing; use a non-auto-vacuum fixture large enough for the intended schema. Preserve the connection's live result-code mask across prepared statements: step, reset, finalize, and therefore exec expose primary codes by default and extended codes only after enabling them. Resolve connection-local eponymous table functions before schema requirements and accept keyword-fallback column tokens, not only `TK_ID`. When a source-faithful replacement invalidates a simplified test expectation, confirm the upstream body and update the stale test rather than restoring the substitute behavior. Pager calls through the typed memory-journal owner must pass a valid SQLite sync mode such as `SQLITE_SYNC_NORMAL`; zero reaches post-spill VFS assertions and is not a valid substitute. Never claim counts, guarantees, completion, integration, or evidence not checked by an existing mechanism/artifact. Independent fidelity review is deferred and is not a current objective or gate.

   - scan multiline and same-line `for`/`while`/optional- or error-capture/nested-`if` assignment chains (including `catch |e| assignment`; use `rg --pcre2` when a pattern contains look-around); brace nested branches and loop/conditional chains;
