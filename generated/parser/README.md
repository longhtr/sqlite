# Generated parser artifacts

- `parser_probe.*` is generated by `tools/generate_parser_probe.py`. It proves deterministic Lemon metadata plus C-parser-to-Zig semantic-action dispatch.
- `sqlite_parse.*` and `sqlite-parser-manifest.json` are generated by `tools/generate_sqlite_parser.py` from the pinned `parse.y`, Lemon source, template, and build predicates. The manifest owns parser counts and source-corresponding semantic-action identities.

These are fidelity inputs and evidence. They are not yet a native Zig parser executor.
